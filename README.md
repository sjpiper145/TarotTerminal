# Tarot Terminal
A software that generates a tarot reading, and prints it for you on a receipt printer!

Credit to [Meghan Trainer](https://www.meghantrainor.com/) - This code was adapted from her amazing Witch Tech class to suit this project.  

This is designed to be installed on a Raspberry Pi and used with a Mini Thermal Receipt printer to print your Tarot readings for a Past, Present and Future spread.  It's written in Python, which means you can adjust the code to suit custom tarot card artworks, sound effects and use your own fonts and colors.  You may also wish to add features for 'reversed' readings and more.  

To use this, you'll need to have Python installed, plus libraries including Pygame-ce, Pillow, and Tkinter.  If this is your first time using python, you may wish to install [PyCharm](https://www.jetbrains.com/pycharm/) or a similar IDE to make it easy to install the libraries used.
